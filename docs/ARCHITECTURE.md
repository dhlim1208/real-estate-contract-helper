## 분석 파이프라인 (6단계)

```
1. 파일 준비          : 이미지 자동 압축 (4MB 한도, 2400px 다운스케일)
2. 서류 정보 추출     : Claude Vision (temperature=0, 결정적)
3. 국토부 실거래가     : MOLIT 공공 API (시군구 단위 주차 집계)
4. 웹 실거래가 보조    : Claude web_search 도구로 매물 사이트 교차검증
5. 전세가율 위험도     : LBR (Loan-to-Bid Ratio) 산정
6. 종합 분석          : Claude (temperature=0.2, 자연스런 문장)
```

각 단계의 temperature·max_tokens 조합은 `index.html` 의 `callAPI` 호출부에서 확인.

## AI 환각 방지 3단 방어

1. **프롬프트 단계**: "서류에 명시된 것만, 추측 금지" 규칙 + 예시
2. **컨텍스트 단계**: 추출 결과(근저당·신탁 등)를 분석 프롬프트에 명시적으로 false/null 주입
3. **JS 검증 단계**: 모순된 조합(예: 채권최고액만 있고 채권자 없음) 자동 무효화

## 보안 모델

- **API 키 노출 방지**: Anthropic·국토부 키는 Vercel 환경변수에만 저장. 프론트는 절대 키를 받지 않음.
- **이미지 데이터**: 클라이언트 → Vercel → Anthropic. 중간 스토리지 없음.
- **로그**: Vercel 함수는 기본 로그만 남기고 사용자 업로드 본문은 로그에 출력하지 않음.
- **CORS**: `Access-Control-Allow-Origin: *` (공용 데모 가정). 사내 한정 사용 시 도메인 제한 권장.

## 주요 환각 방지 패턴

- 본문 조항(제1조~제9조)을 특약으로 잘못 추출하는 것 방지: 추출 프롬프트 내 ❌/✅ 예시 + 클라이언트 사이드 정규식 필터(`isStandardBodyClause`).
- 신탁/공공 소유 부동산: 등기부 갑구의 "가장 큰 순위번호" 행만 유효하다는 명시적 규칙.
- 근저당이 여러 건일 때: 합계 또는 최댓값으로 보수적 평가.

## 결정적 동작 보장

같은 서류를 여러 번 올려도 동일한 결과가 나오도록:
- 추출 단계: `temperature: 0, max_tokens: 6000`
- 종합 분석: `temperature: 0.2` (문장만 약간 자연스럽게)
- 국토부 응답은 결정적 (정렬·집계만)

## 확장 포인트

- **모델 교체**: `proxy/api/claude.js` 에 모델명 강제하지 않음. 프론트가 `model` 파라미터 결정.
- **프록시 별도 도메인**: `index.html` 상단의 `API_BASE_URL` 상수만 변경하면 됨.
- **타임아웃 확장**: `proxy/vercel.json` 의 `maxDuration` (Hobby 60s, Pro 300s).
